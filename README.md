## 一、GitHub Pages 開啟設定

本倉庫已內建自動發佈流程 `.github/workflows/deploy.yml`，每次 push 到 `main` 會自動檢查語法並發佈。

若是 fork 或新建倉庫，首次請手動開啟：

1. 進入 GitHub 倉庫 → **Settings** → 左側 **Pages**。
2. **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 到 **Actions** 分頁確認「Deploy to GitHub Pages」執行成功（綠色勾勾）。
4. 網址為 `https://<帳號>.github.io/<倉庫名稱>/`。

> 免費帳號的 GitHub Pages 需要公開倉庫。網站已加上 `noindex`，不會被搜尋引擎收錄；所有票數只存在操作筆電的瀏覽器內，不會上傳到任何伺服器。

**路由說明**：全站只有 `index.html` 一個頁面，以 `?mode=admin` 或 `#/admin` 切換後台，重新整理不會出現 404。

## 二、筆電＋投影機雙螢幕操作指南

### 1. 硬體連接

1. 筆電以 HDMI 連接投影機。
2. Windows 按 <kbd>Win</kbd> + <kbd>P</kbd> → 選 **延伸**（不要選「同步顯示」）。
3. 建議投影機解析度設為 1920×1080（16:9），畫面會自動等比放大。

### 2. 開啟兩個視窗（**務必使用同一個瀏覽器**，建議 Chrome 或 Edge）

1. 開啟投影戰情牆網址，將視窗拖到投影機螢幕。
2. 在戰情牆按 <kbd>F</kbd>（或按兩下畫面）進入全螢幕；右下角的「開啟計票後台視窗」捷徑會自動隱藏，滑鼠 3 秒不動也會自動隱藏。
3. 在筆電螢幕開啟後台：按戰情牆右下角捷徑、在戰情牆按 <kbd>A</kbd>，或直接輸入 `?mode=admin` 網址。
4. 後台右上角顯示「**投影牆已連線 ×1**」即代表同步正常。

> ⚠ 兩個視窗必須是同一個瀏覽器、同一個瀏覽器設定檔，且**不可使用無痕模式**，否則無法同步。

### 3. 斷網備援

- 開票前先在有網路時開啟一次前後台，系統會自動快取網頁；之後即使斷網，重新整理也能正常載入。
- 所有資料存在瀏覽器 `localStorage`，誤關分頁或重新整理都不會遺失。

## 三、後台極速計票流程（單手數字鍵盤）

```
輸入編號 57 → Enter → 1 號票數 → Enter → 2 號 → Enter → 3 號 → Enter → 4 號 → Enter（送出）
                                                                        ↓
                                              投影牆即時更新，游標自動回到編號框待命
```

| 按鍵 | 功能 |
| --- | --- |
| 編號框輸入 `57`～`95` 或 `0357`～`0395` + <kbd>Enter</kbd> | 鎖定投開票所，跳到 1 號票數欄 |
| 票數欄 <kbd>Enter</kbd> | 跳下一號；在 4 號欄則直接送出 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 在票數欄上下移動 |
| <kbd>-</kbd>（數字鍵盤減號） | 切換「已開完」／「期中回報」 |
| <kbd>Esc</kbd> | 回到編號框 |
| <kbd>Alt</kbd> + <kbd>Z</kbd> | 還原上一筆操作 |
| 對話框 <kbd>Enter</kbd> / <kbd>Esc</kbd> | 確認／返回修改 |

- **3 號林義剛**的輸入欄有藍底金框，避免填錯格。
- **已開完**（預設）計入完成率；**期中回報**可隨時用新數字覆蓋。再次輸入同一所即可更新。
- 右側 **39 所狀態總覽**：灰＝未回報、黃＝期中、綠＝已開完；點任一格可載入原票數修改。
- **防呆**：單所單一候選人超過 1,500 票會跳出二次確認（防多打一個 0）；四人皆 0 票也會提醒。
- 輸入錯誤可按「清除本所回報」或「還原上一筆」（最多保留 40 步）。

## 四、選前準備與資料安全

**選前一週**

1. 開啟後台 →「📋 批次貼上村別／地點」，從 Excel 複製「編號／村別／地點」三欄直接貼上（Tab、逗號或空白分隔皆可），預覽無誤後套用。也可在鎖定單一所後，用編號旁的下拉選單逐所標註。
2. 用「🎲 模擬隨機開票」演練數次，確認投影效果、名次動畫與當選線。
3. 演練完按「🗑 清空全部票數」，輸入「清空全部」確認（村別／地點標註會保留）。

**開票當晚**

- 每開完約 10 所，按一次「⬇ 匯出 JSON 備份」。
- 若需換電腦，用「⬆ 匯入 JSON 還原」即可接續。
- 開票結束後按「📄 匯出 39 所戰報 CSV」，檔案為 UTF-8 BOM 格式，Excel 直接開啟不會亂碼，內含各所票數、合計、得票率與名次。

## 五、投影戰情牆畫面說明

- **頂部狀態列**：選舉名稱、即時時鐘、已開完所數與百分比、期中回報所數、累計有效票。
- **林義剛核心戰報卡**：號次徽章、目前排名、累計得票（跳動動畫）、得票率。
  - 第 1～3 名：綠色顯示「目前領先第 4 名（落選頭）+X 票」。
  - 第 4 名：紅色閃爍顯示「距離第 3 名（當選門檻）尚差 −X 票」。
- **4 人即時排名**：依得票自動排序並平滑換位，第 3、4 名之間有發光當選線。
- **最新開票快訊**：最近回報的 3 所及各候選人得票。

## 六、專案結構與本機開發

```
index.html              單一入口頁面
css/base.css            共用色票與字體
css/board.css           投影戰情牆樣式
css/admin.css           後台計票台樣式
js/data.js              選區、候選人、投開票所資料
js/store.js             localStorage 儲存、BroadcastChannel 同步、Undo、排名計算
js/board.js             投影戰情牆
js/ui.js                鍵盤友善對話框與提示
js/admin.js             後台計票台
js/tools.js             備份、CSV、模擬開票、批次匯入
js/app.js               模式路由與離線快取註冊
sw.js                   離線快取 Service Worker
.github/workflows/      GitHub Pages 自動發佈
```

本機預覽（不需安裝任何套件）：

```bash
python -m http.server 8000
# 投影牆 http://localhost:8000/
# 後台   http://localhost:8000/?mode=admin
```

也可以直接雙擊 `index.html` 以 `file://` 開啟（此方式不提供離線快取）。

### 修改候選人或投開票所

所有選舉資料集中在 `js/data.js`：候選人姓名、政黨、代表色、應選席次、投開票所編號範圍、單所高票門檻（`highVoteThreshold`）。
